# スチャラカトレイン ゲームデザイン

## コンセプト

「桃鉄の仕組みを一直線の路線に押し込んだらどうなるか」という実験的MMOボードゲーム。

北陸鉄道・のと鉄道は駅数が少なく、ほぼ一直線。この制約が桃鉄のメカニクスに独特のカオスを生む:

- **貧乏神**: 追い越すたびに相手に移る → 一直線なので押し付け合いが終わらない
- **うんちカード**: 迂回路がないので実質「完全封鎖」
- **プレイヤー密度**: 全員が同じ線路上 → 衝突・干渉が頻発
- **MMO**: 人数が増えるほどカオスが加速

## ゲームルール

### サイコロ

- mypace（Nostrクライアント）に投稿するたびに1回振れる
- 投稿しないと進めない（放置ゲーにならない）

### 目的地

- 桃鉄と同様、目的地が設定される
- 最初に到着したプレイヤーが報酬を得る

### 物件

各駅・マス周辺に実在するローカルな店・食べ物・公園を物件にする。

**方針:**
- 観光ガイドに載るような「あざとい名物」は使わない
- 地元の人しか知らないB級グルメ、個人経営の菓子店、近所の子が遊ぶ公園など
- すごくマイナーであることが価値（「なにこれ？」が面白さ）
- 実在の店名・商品名を使う（許可が取れるものは取る、難しければモチーフ程度に）

**物件の例（調査が必要）:**
- 駅前の個人菓子店（○○饅頭、△△餅）
- ローカルなB級グルメ（地元スーパーの惣菜、商店街の焼きそば等）
- 近所の公園、児童館
- 銭湯、理髪店
- 地元で有名なだけの食堂

**物件調査のルール:**
- 北陸鉄道石川線・浅野川線・のと鉄道の各駅周辺を調べる
- Google Mapsのストリートビュー、地元ブログ、食べログの低レビュー数の店が狙い目
- 「わざわざ紹介するほどでもない」ものこそ正解

### カード

**設計方針: 赤字で嫌にならないゲーム**

一直線の路線では貧乏神の押し付け合いや封鎖が激しく、赤字に陥りやすい。カードは「救済・逆転・バランス調整」を厚めにし、負けていても楽しい状態を維持する。

**金銭バランス調整系（多め）:**
- **たいらのまさカード**: 借金をチャラにする（徳政令の前段階）
- **徳政令カード**: 全プレイヤーの借金を帳消し（全体リセット）
- **赤字補填カード**: 赤字物件の収支を一定期間プラスにする
- **北陸銀行カード**: 低金利で借金を借り換え（利息軽減）

**移動系（一直線を活かす）:**
- **急行カード**: サイコロ2倍で進む
- **逆走カード**: 進行方向を反転する
- **ワープカード**: 指定した駅に飛ぶ
- **うんちカード**: マスを封鎖する（迂回不可なので超強力、入手困難にする）

**攻撃・妨害系:**
- **貧乏神押し付けカード**: 自分の貧乏神を指定プレイヤーに飛ばす
- **運休カード**: 指定プレイヤーを1ターン休みにする

**特殊系:**
- **福の神カード**: 幻想モード発動
- **延伸カード**: 未来モードの路線を一時的に開放

**バランス原則:**
- 救済系カードは入手しやすく、妨害系は入手しにくい
- うんちカードは最強だが最レア（一直線では完全封鎖になるため）
- 赤字が続くプレイヤーには救済カードが出やすい（天秤補正）

### 貧乏神

- 追い越したときに相手に付く（桃鉄準拠）
- 一直線なので往復するたびに移り続ける

## マップ

### 路線

実在の北陸鉄道・のと鉄道の路線をベースにする。駅数が少ないため、駅間に実在の町名を使った架空マスを配置して密度を上げる。

```
[金沢]--○--[野町]--○--○--[額住宅前]--○--○--[鶴来]--...--[白山下(廃)]
         ↑
    実在の町名で架空マス（30〜50マス程度）
```

### マップ描画

- **Googleマップに似た見た目**だが、回転可能にする
- 北を上に固定すると退屈なので、ユーザーが自由に回転できる
- ピンチ操作やドラッグで拡大・縮小・回転
- 路線とマスはマップ上にオーバーレイ表示
- 実装: Canvas上に地図タイル（or 自作の簡略マップ）を描画し、transform で回転

### モード

- **通常モード**: 現在の北陸鉄道路線
- **幻想モード**: 福の神で発動。特殊演出
- **未来モード**: へぐら駅、のとじま縦断など、架空の延伸路線が出現

### 路線バリエーション（メモ段階）

- **N鉄道**（軟体鉄道）: たこじま、イカキング
- **H鉄道**（エッジ鉄道）: つるぎ

### 路線エディット

将来的にユーザーが自由に路線を追加できるエディット機能を開放する。

## プレイヤー

### 登録プレイヤー

- mypace投稿でサイコロを振る
- 物件購入・カード使用を自分で判断
- 電車アイコン + 名前 + 所持金が表示される

### NPC（自動プレイヤー）

- Nostrリレーに流れる公開投稿（mypace以外含む）で自動的にサイコロが振られる
- 物件は自動購入（簡易AI: 安い物件を優先する等）
- 貧乏神もNPCに付く
- 見た目は登録プレイヤーと同じ電車
- Nostr全体の投稿量 = ゲーム世界の賑わい

### オフラインプレイヤー

- ブラウザを閉じても常時セーブ
- 電車は路線外の側線に退避した描画になる（消えない）
- 再度開くと復帰

## 「赤字」

北陸鉄道のリアルな経営状況をゲームに反映する要素（詳細未定）。
