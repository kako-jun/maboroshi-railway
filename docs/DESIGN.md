# スーパーまぼろし鉄道サニールネッサンス線 ゲームデザイン

## コンセプト

「桃鉄の仕組みを一直線の路線に押し込んだらどうなるか」という実験的MMOボードゲーム。

北陸鉄道・のと鉄道は駅数が少なく、ほぼ一直線。この制約が桃鉄のメカニクスに独特のカオスを生む:

- **貧乏神**: 追い越すたびに相手に移る → 一直線なので押し付け合いが終わらない
- **うんちカード**: 迂回路がないので実質「完全封鎖」
- **プレイヤー密度**: 全員が同じ線路上 → 衝突・干渉が頻発
- **MMO**: 人数が増えるほどカオスが加速

## ゲームルール

### サイコロ・時間経過

- mypace（Nostrクライアント）に投稿するたびに1回振れる
- 投稿しないと進めない（放置ゲーにならない）
- **サイコロ1回 = ゲーム内1ヶ月**（1月→2月→...→12月→翌年1月）
- 7月に七夕イベントが発動する（= サイコロ7回ごとに七夕が来る可能性）

### 目的地

- 桃鉄と同様、目的地が設定される
- 最初に到着したプレイヤーが報酬を得る

### 物件

各駅・マス周辺に実在するローカルな店・食べ物・公園を物件にする。

**方針:**
- 観光ガイドに載るような「あざとい名物」は使わない
- 地元の人しか知らないB級グルメ、個人経営の菓子店、近所の子が遊ぶ公園など
- すごくマイナーであることが価値（「なにこれ？」が面白さ）
- 実在の店名・商品名を使う（許可が取れるものは取る、難しければモチーフ程度に）

**物件の例（調査が必要）:**
- 駅前の個人菓子店（○○饅頭、△△餅）
- ローカルなB級グルメ（地元スーパーの惣菜、商店街の焼きそば等）
- 近所の公園、児童館
- 銭湯、理髪店
- 地元で有名なだけの食堂

**所有ルール:**
- 物件は独占不可。誰でも何回でも購入できる
- 他プレイヤーの購入状況は見える（「○人が購入済み」と表示）
- 増資も各プレイヤーが独立して行える
- 収益は購入した全員がそれぞれ得る
- 後発プレイヤーでも全物件を買える（MMOで途中参加しても詰まない）

**物件調査のルール:**
- 北陸鉄道石川線・浅野川線・のと鉄道の各駅周辺を調べる
- Google Mapsのストリートビュー、地元ブログ、食べログの低レビュー数の店が狙い目
- 「わざわざ紹介するほどでもない」ものこそ正解

### カード

**設計方針: 赤字で嫌にならないゲーム**

一直線の路線では貧乏神の押し付け合いや封鎖が激しく、赤字に陥りやすい。カードは「救済・逆転・バランス調整」を厚めにし、負けていても楽しい状態を維持する。

**金銭バランス調整系（多め）:**
- **たいらのまさカード**: 借金をチャラにする（徳政令の前段階）
- **徳政令カード**: 全プレイヤーの借金を帳消し（全体リセット）
- **赤字補填カード**: 赤字物件の収支を一定期間プラスにする
- **北陸銀行カード**: 低金利で借金を借り換え（利息軽減）

**移動系（一直線を活かす）:**
- **急行カード**: サイコロ2倍で進む
- **逆走カード**: 進行方向を反転する
- **ワープカード**: 指定した駅に飛ぶ
- **うんちカード**: マスを封鎖する（迂回不可なので超強力、入手困難にする）

**攻撃・妨害系:**
- **貧乏神押し付けカード**: 自分の貧乏神を指定プレイヤーに飛ばす
- **運休カード**: 指定プレイヤーを1ターン休みにする

**特殊系:**
- **福の神カード**: 幻想モード発動
- **延伸カード**: 未来モードの路線を一時的に開放

**バランス原則:**
- 救済系カードは入手しやすく、妨害系は入手しにくい
- うんちカードは最強だが最レア（一直線では完全封鎖になるため）
- 赤字が続くプレイヤーには救済カードが出やすい（天秤補正）

### 貧乏神 → 福の神への変化

- 追い越したときに相手に付く（桃鉄準拠）
- 一直線なので往復するたびに移り続ける
- **押し付け合いが一定回数に達すると、貧乏神が福の神に変化する**
- プレイヤー間をたらい回しにされるうちに浄化されるイメージ
- 福の神に変わると幻想モードが発動（昭和の廃線・廃駅が復活）
- 福の神は一定期間（数年分 = 数十ターン）プレイヤー全員に恩恵を与えた後、消える
- 幻想モードの持続期間は「1年では回りきれない」程度に長い（廃線の物件を買い集める時間が必要）
- 消えた後、また新たな貧乏神がどこかに出現する
- つまり: 貧乏神の押し付け合い → 皆の協力で福の神に → 幻想モード → 終了 → 次の貧乏神、のサイクル

### 勝利条件・ゲーム終了

**なし。** 勝利も敗北も終わりもない。エンドレスで遊び続ける。

- 桃太郎ランドに相当する最高額物件は存在する（北陸版の何か）
- 買えばキリは良いが、増資ができるのでそこで終わりにはならない
- 増資回数に上限なし
- 所持金・物件総額のランキングは表示するが、勝敗判定はしない
- いつ始めてもいつやめてもいい

## マップ

### 路線

実在の北陸鉄道・のと鉄道の路線をベースにする。駅数が少ないため、駅間に実在の町名を使った架空マスを配置して密度を上げる。

```
[金沢]--○--[野町]--○--○--[額住宅前]--○--○--[鶴来]--...--[白山下(廃)]
         ↑
    実在の町名で架空マス（30〜50マス程度）
```

### マップ描画

- **Googleマップに似た見た目**だが、回転可能にする
- 北を上に固定すると退屈なので、ユーザーが自由に回転できる
- ピンチ操作やドラッグで拡大・縮小・回転
- 路線とマスはマップ上にオーバーレイ表示
- 実装: Canvas上に自作マップを描画し、transform で回転

### マップ素材の作り方

実際の地図（OpenStreetMap）や航空写真を参考に、ゲーム用の簡略マップを生成する。

1. OpenStreetMap or 航空写真から北陸鉄道沿線エリアを切り出す
2. 地形の輪郭だけをトレース（海岸線・山・川・主要道路）
3. 余計な文字・建物・情報を削ぎ落とす
4. ゲーム用の色・テクスチャで塗り直す
5. その上に路線とマスを配置

リアルな地形のシルエットは保ちつつ、回転しても文字が傾かないクリーンなマップにする。

### 路線構成

2つの独立した路線がある。どちらも赤字。

- **北陸鉄道**（石川線・浅野川線）: 金沢周辺
- **のと鉄道**（七尾線）: 能登半島

通常は2路線は繋がっていない（実際に繋がっていない）。プレイヤーはどちらかの路線にいる。

### 七夕イベント（7月）

毎年7月、2路線が「七夕」として一時的に繋がる。

- 7月1日〜7月7日の期間限定で架空の連絡線が出現
- 普段行けない路線に移動できる
- 両路線のプレイヤーが合流し、カオスが一気に加速
- 期間が終わると連絡線が消え、その時いた路線に取り残される
- 七夕限定物件（両路線の間にある架空の店）が登場

### モード

- **幻想モード**: 福の神で発動。最盛期に存在した廃線・廃駅が一時的に復活する
  - **北陸鉄道**: 金沢市内線（路面電車）・能美線・金名線・加南線など。一直線だったマップに分岐が大量出現し、ゲーム性が一変する
  - **のと鉄道**: 穴水〜蛸島間（珠洲方面）・輪島線が復活。能登半島の先端まで行ける
  - 廃駅周辺にも当時の物件が出現する
  - **幻想モード限定の目玉物件**:
    - 北陸鉄道: サニーランド、ルネスかなざわ（最高額）
    - のと鉄道: シーサイド（最高額）
    - タイトル「サニールネッサンス」はサニーランド+ルネスかなざわの由来。地元民にだけ伝わる
  - **幻想モードは期間限定**。期間が終わると廃線区間は再び消える（夢から覚める）
  - 消える区間にいたプレイヤーは、通常モードの最寄りの端の駅に戻される
  - 幻想中に購入した物件は消えない。収益も出続ける。ただし次の幻想モードまでその駅には行けない（増資できない）
- **未来モード**: へぐら駅、のとじま縦断など、架空の延伸路線が出現

### 路線の別名と最高額物件

| 路線 | 別名 | 地域 | モチーフ | 最高額物件（幻想モード限定） |
|---|---|---|---|---|
| **北陸鉄道** | H鉄道（エッジ鉄道） | 加賀 | つるぎ | ルネスかなざわ |
| **のと鉄道** | N鉄道（軟体鉄道） | 能登 | たこじま、イカキング | シーサイド |

### 路線エディット

将来的にユーザーが自由に路線を追加できるエディット機能を開放する。

## プレイヤー

### 登録プレイヤー

- 初回登録時にスタート路線が1/2のランダムで決まる（北陸鉄道 or のと鉄道）
- 七夕イベント（7月）以外は路線を移動できない。七夕終了時にいた路線に来年まで残る
- mypace投稿でサイコロを振る
- 物件購入・カード使用を自分で判断
- 電車アイコン + 名前 + 所持金が表示される

### NPC（自動プレイヤー）

- Nostrリレーに流れる公開投稿（mypace以外含む）で自動的にサイコロが振られる
- 物件は自動購入（簡易AI: 安い物件を優先する等）
- 貧乏神もNPCに付く
- 見た目は登録プレイヤーと同じ電車
- Nostr全体の投稿量 = ゲーム世界の賑わい

### オフラインプレイヤー

- ブラウザを閉じても常時セーブ
- 電車は路線外の側線に退避した描画になる（消えない）
- 再度開くと復帰

## 世界観

**七福神的な和風・神様の世界観で統一する。**

北陸の鉄道を神々が見守っている。プレイヤーたちは神々の力を借りながら、赤字路線を立て直す。

- 貧乏神 → 福の神への浄化（皆の協力で）
- 七夕で路線が繋がる（織姫と彦星のように年に一度）
- 幻想モードで昭和の路線が蘇る（神様の夢）
- カード名も和風に寄せる（たいらのまさカード、徳政令カード等）
- ゲーム内の演出・UI・アイコンも和風意匠（七福神、神社、御札、絵馬など）
- **メニュー・ボタン等のUI部品も和風デザインで統一**: 巻物風メニュー、御札風ボタン、墨書き風フォント、和紙テクスチャ背景など。モダンUIに和風スキンを被せるのではなく、世界観の中にUIが溶け込む設計にする

## ストーリー

### 赤字返済という大目標

北陸鉄道は赤字経営。プレイヤー全員で沿線を活性化し、赤字を返済するのがゲーム全体のストーリー。

**対戦ではなく協力。** 競うのではなく、一緒に立て直す。

- 物件を買う = 沿線の活性化 = 鉄道の赤字が減る
- 全プレイヤーの物件購入・増資が「鉄道全体の赤字残高」を削っていく
- 赤字残高はゲーム画面に常時表示（全員で共有するゲージ）
- 貧乏神は復興の足を引っ張る存在（個人を攻撃し、結果的に全体の貢献が遅れる）

### 貢献度

プレイヤーの価値は所持金ではなく「どれだけ赤字返済に貢献したか」で測る。

- **貢献度**: 物件購入額・増資額の累計で計算
- 貢献度ランキングが表示される
- 高貢献者には称号が付く（例: 「鶴来の恩人」「野町の救世主」）
- 駅やマスに貢献者の名前が表示される（最多貢献者）
- 貢献度は減らない（赤字になっても過去の貢献は消えない）

### 赤字が全額返済されたら？

- 全員で祝う演出が入る
- しかしゲームは終わらない。新たな赤字（路線延伸、車両更新等）が発生し、次の目標が始まる
- 「第○期」のように時代が進む
